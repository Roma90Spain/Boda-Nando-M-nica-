# 🎾 Torneo de Pádel - Boda de Nando y Mónica

Aplicación web para organizar torneos de pádel con generación aleatoria de parejas y emparejamientos.

![HTML5](https://img.shields.io/badge/HTML5-E34F26?style=flat-square&logo=html5&logoColor=white)
![CSS3](https://img.shields.io/badge/CSS3-1572B6?style=flat-square&logo=css3&logoColor=white)
![JavaScript](https://img.shields.io/badge/JavaScript-F7DF1E?style=flat-square&logo=javascript&logoColor=black)

## ✨ Características

- ✅ Agregar jugadores con género (Hombre/Mujer)
- ✅ Generación aleatoria de parejas
- ✅ Algoritmo inteligente que evita parejas de solo mujeres
- ✅ Generación de emparejamientos para partidos
- ✅ Visualización de partidos por jornadas
- ✅ Contraseña protegida para acciones críticas
- ✅ Datos persisten en localStorage del navegador
- ✅ Diseño responsive (desktop y móvil)
- ✅ Interfaz moderna y atractiva

## 🚀 Inicio Rápido

### Opción 1: GitHub Pages (Recomendado)

1. Crea un repositorio nuevo en GitHub llamado `torneo-padel`
2. Sube estos archivos:
   - `index.html`
   - `README.md`
3. Ve a Settings → Pages → Source → selecciona `main` branch
4. Tu app estará disponible en: `https://tu-usuario.github.io/torneo-padel`

### Opción 2: Local

Simplemente abre el archivo `index.html` en tu navegador. No necesita servidor.

## 📖 Cómo Usar

### 1️⃣ Agregar Jugadores
- Escribe el nombre en el campo de texto
- Selecciona el género (Hombre 👨 o Mujer 👩)
- Haz clic en **Agregar Jugador**

### 2️⃣ Generar Parejas
- Haz clic en **Generar Parejas (Aleatorio)** 🔀
- Introduce la contraseña: `BodaNyM`
- Las parejas se crearán aleatoriamente, evitando que dos mujeres estén juntas (si es posible)

### 3️⃣ Generar Emparejamientos
- Haz clic en **Generar Emparejamientos** ⚔️
- Introduce la contraseña: `BodaNyM`
- Los partidos se crearán aleatoriamente y se organizarán por jornadas

### 4️⃣ Ver Partidos
- Haz clic en **Ver Partidos** 👀
- Se mostrarán todos los partidos organizados por jornadas

## 💾 Almacenamiento

Los datos se guardan automáticamente en el **localStorage** del navegador:
- Los datos persisten cuando cierras la pestaña
- Los datos se limpian si ejecutas "Limpiar Todo"
- Puedes usar diferentes navegadores y tendrás datos independientes
